# 🚀 Technoit – IT & Technology Services Template
[Live Demo](https://bola-nabil.github.io/Technoit/)

---
## 📖 Description
**Technoit** is a modern, responsive, one-page / multi-section template tailored for **IT service providers**, tech startups, agencies, or businesses offering digital solutions.  
It features smooth animations, distinct sections (Services, Portfolio, Team, Pricing, FAQ, Blog, Contact), and is SEO-friendly and customizable.  

It aims to help tech companies showcase their services, projects, team, pricing tiers, and thought leadership in a clean and professional design.

## ✨ Features 
- Parallax & scrolling animations  
- Sections for **Home, About, Services, Portfolio, Pricing, Testimonials, Team, FAQ, Blog, Contact**  
- Responsive design for desktop, tablet, and mobile  
- SEO-friendly structure and markup  
- Customizable and modular layout  
- Pricing tables, testimonials, blog, team sections built-in  
- Contact form / quote request UI

---
## 🛠️ Tech Stack
- **HTML5** – structure & semantic layout  
- **CSS3 / Sass (SCSS)** – styling and responsive design  
- **JavaScript** – for interactive effects, menu toggling, smooth scroll, etc.  
- **Images & Icons** – visual elements and decorations
